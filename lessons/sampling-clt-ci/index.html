開場

我們想知道的事，常常問不完

1

EAI 公司想了解 2,500 位經理的資料，但手上沒有全部的資料，只能抽 30 位當樣本

2

樣本只是母體的一部分，所以只能得到母體的估計值

3

抽樣一定存在誤差，有代表性的樣本誤差比較小，樣本不夠多誤差比較大

2,500 個點代表母體，深色的 30 個是抽到的樣本（位置為隨機示意）

第一部分：基本工具

想知道的叫母體參數，手上有的叫樣本統計量

母體（想知道的）

  • 資料個數$N$
  • 平均數$\mu$
  • 變異數$\sigma^2$
  • 標準差$\sigma$

固定的數字，但通常不知道

樣本（手上有的）

  • 資料個數$n$
  • 平均數$\bar{x}$
  • 變異數$s^2$
  • 標準差$s$

算得出來，但每次抽樣都不一樣

用樣本猜母體

$\bar{x}$ 是 $\mu$ 的點估計量，$s^2$ 是 $\sigma^2$ 的點估計量

隨機抽樣的條件

每個可能的樣本被抽中的機率相同，每個元素獨立選取，而且和母體同分配（iid）

第一部分：基本工具

工具一：用兩個數字描述一組資料

平均數：中心在哪裡

$\bar{x} = \dfrac{\sum x_i}{n}$

標準差：有多分散

$s = \sqrt{\dfrac{\sum (x_i - \bar{x})^2}{n-1}}$

分母是 $n-1$：算 $\bar{x}$ 用掉了一個自由度

例子：5 個班級的人數 46、54、42、46、32

$\bar{x} = 44$，$s = 8$

第一部分：基本工具

工具二：常態分配

最重要

機率 = 曲線下的面積

總面積為 1；單一點的機率為 0，所以有沒有等號機率都一樣

左右對稱

平均數 = 中位數 = 眾數

常見誤解：曲線的高度不是機率，面積才是

拖動滑桿，看 $\mu$ 和 $\sigma$ 怎麼改變曲線；淺色虛線是 $\mu = 0$、$\sigma = 1$ 的曲線

第一部分：基本工具

工具三：經驗法則

範圍比例
$\mu \pm 1\sigma$68.26%
$\mu \pm 2\sigma$95.45%
$\mu \pm 3\sigma$99.73%

例子：洗衣精填充重量

平均 16 盎司、標準差 0.25 盎司的鐘形分配
15.75 到 16.25：68.26%
15.50 到 16.50：95.45%
15.25 到 16.75：99.73%

第一部分：基本工具

工具四：標準化，換一把尺再查表

$Z = \dfrac{X - \mu}{\sigma} \sim N(0, 1)$

z 的意思是「離平均數幾個標準差」

查表

z 表給的是 z 左邊的累積面積

$P(z \le 1.00) = 0.8413$

$P(-1 \le z \le 1) = 0.8413 - 0.1587 = 0.6826$

就是經驗法則的 68.26%

反查

右尾面積 0.05 對應 $z = 1.645$，之後算信賴區間會用到

第二部分：抽樣分配與中央極限定理

關鍵轉折：$\bar{x}$ 也是隨機變數

估計量（大寫）

$\bar{X} = \dfrac{X_1 + \dots + X_n}{n}$

是數學式，抽之前不知道結果，是隨機變數

點估計值（小寫）

$\bar{x} = 1684$

把抽到的資料代進去算出來的數字

例子：St. Andrew's College 從 900 位申請者中抽 30 位

母體參數真正的值點估計值
SAT 平均 $\mu$1697$\bar{x} = 1684$
SAT 標準差 $\sigma$87.4$s = 85.2$
想住校的比例 $p$0.72$\bar{p} = 0.67$
接近但不相等，換一組樣本，抽到的人不一樣，$\bar{x}$ 也會不一樣

→

→

示意圖：依 $E(\bar{x}) = 51{,}800$、標準誤差 730.3 模擬產生，不是講義原圖

看三件事

是否對稱、中心在哪、有多分散

分清楚三種分配補充

樣本：這 30 個人的數值
抽樣分配：很多組樣本各自算出的 $\bar{x}$

第二部分：抽樣分配與中央極限定理

抽樣分配的中心與寬度

中心

$E(\bar{x}) = \mu$

$\bar{x}$ 平均來說剛好等於 $\mu$，所以 $\bar{x}$ 是不偏的

寬度

$\sigma_{\bar{x}} = \dfrac{\sigma}{\sqrt{n}}$

叫做標準誤差（standard error）

推導（前提：$X_1, \dots, X_n$ 為 iid，每個 $X_i \sim (\mu, \sigma^2)$）

$E(\bar{X}) = \frac{1}{n}\left[E(X_1) + \dots + E(X_n)\right] = \frac{n\mu}{n} = \mu$

$V(\bar{X}) = \frac{1}{n^2}\left[V(X_1) + \dots + V(X_n)\right] = \frac{n\sigma^2}{n^2} = \frac{\sigma^2}{n}$

第二部分：抽樣分配與中央極限定理

互動模擬：中央極限定理

第二部分：抽樣分配與中央極限定理

中央極限定理：樣本要多大才夠

從母體抽出大小為 $n$ 的隨機樣本，$n$ 夠大時，$\bar{X} \sim N\!\left(\mu, \dfrac{\sigma^2}{n}\right)$
母體的情況樣本數
母體本身是常態分配任何樣本數，$\bar{x}$ 都是常態
母體至少近似常態$n$ 小於 15 也可以
不是常態但大致對稱$n = 15$ 就夠
多數應用$n \ge 30$
母體高度偏斜或有離群值可能需要 $n = 50$

回想剛才的模擬：右偏母體最慢變成鐘形，所以偏斜的母體需要比較大的 $n$補充

第二部分：抽樣分配與中央極限定理

標準誤差：樣本越大，估計越準

EAI 例子：$\mu = 51{,}800$、$\sigma = 4{,}000$，陰影是 $\mu \pm 500$

$n = 30$$n = 100$
標準誤差730.3400
$\bar{x}$ 落在 $\mu \pm 500$ 的機率0.50340.7888

$\sigma_{\bar{x}} < \sigma$，$n$ 越大，$\bar{x}$ 的曲線越陡、越集中在 $\mu$ 附近

易錯：$\dfrac{\sigma^2}{n}$ 是 $\bar{X}$ 的變異數，標準誤差要開根號，是 $\dfrac{\sigma}{\sqrt{n}}$
第三部分：信賴區間

從中央極限定理到信賴區間

前提：$\bar{X}$ 近似常態分配，也就是 $X \sim N(\mu, \sigma^2)$，或 $n \ge 30$ by CLT，作答時一定要寫出來
1

標準化，兩尾各留 $\alpha/2$

$P\!\left(-z_{\alpha/2}\frac{\sigma}{\sqrt{n}} < \bar{X} - \mu < z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right) = 1 - \alpha$

2

移項，把 $\mu$ 留在中間

$P\!\left(\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}} < \mu < \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right) = 1 - \alpha$

3

代入資料

$\bar{x} \pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$

上界跟下界不要寫反

$1 - \alpha$ 叫做信賴係數，$z_{\alpha/2}$ 是右尾面積為 $\alpha/2$ 的 z 值

第三部分：信賴區間

例子：Lloyd's 百貨的顧客平均花費

已知$\sigma = 20$、$n = 100$
→
標準誤差$\dfrac{20}{\sqrt{100}} = 2$
→
邊際誤差$1.96 \times 2 = 3.92$
→
區間$82 \pm 3.92$

最近一週 $\bar{x} = 82$，95% 信賴區間是 78.08 到 85.92

有 95% 的信心，這個區間包含所有顧客的平均花費 $\mu$

信賴水準$\alpha$$z_{\alpha/2}$
90%0.101.645
95%0.051.960
99%0.012.576
第三部分：信賴區間

互動模擬：「95% 信賴」到底是什麼意思

還沒開始

模擬設定：假設真正的 $\mu = 80$（自訂數字）、$\sigma = 20$、$n = 100$，每個樣本算出 $\bar{x} \pm 3.92$；綠色包含 $\mu$，紅色沒包含；隨機模擬，每次結果不同

用這個方法建立的區間，有 95% 會包含 $\mu$，所以對手上這一個區間說「有 95% 的信心」
第三部分：信賴區間

區間寬度：信心與精準的取捨

信賴水準邊際誤差信賴區間
90%3.2978.71 到 85.29
95%3.9278.08 到 85.92
99%5.1576.85 到 87.15

邊際誤差

$E = z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$，區間寬度 = $2E$

信賴水準越高，區間越寬；$n$ 越大，區間越窄

反推樣本數

$n = \left(\dfrac{z_{\alpha/2}\,\sigma}{E}\right)^2$

95% 信賴、$\sigma = 9.65$、希望 $E = 2$：$n = 89.43$，無條件進位取 90

第三部分：信賴區間

如果不知道 $\sigma$

$\sigma$ 已知

$\bar{x} \pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$

$\sigma$ 未知，$n < 30$

$\bar{x} \pm t_{\alpha/2}(n-1)\dfrac{s}{\sqrt{n}}$

母體是常態或不嚴重偏離常態

$\sigma$ 未知，$n \ge 30$

$\bar{x} \pm z_{\alpha/2}\dfrac{s}{\sqrt{n}}$

$n$ 很大時 t 分配近似標準常態

t 分配比標準常態矮胖，自由度越大越接近標準常態

註：講義的做法是 $\sigma$ 未知一律用 t，並說自由度超過 100 時 z 才是 t 的好近似；本簡報採用筆記的做法，細節見 Wiki

常見誤解整理

誤解正確的說法
樣本夠大，資料就會變成常態中央極限定理說的是 $\bar{x}$ 的分配，母體和樣本資料的形狀不會改變
$n \ge 30$ 永遠夠用母體高度偏斜或有離群值時，可能要 $n = 50$
標準誤差是 $\dfrac{\sigma^2}{n}$$\dfrac{\sigma^2}{n}$ 是變異數，標準誤差是 $\dfrac{\sigma}{\sqrt{n}}$
$\mu$ 有 95% 的機率在這個區間裡$\mu$ 是固定的數字，會變的是區間；95% 是這個方法的成功率
曲線的高度就是機率連續型的機率是曲線下的面積

總結：一條概念鏈

隨機抽樣抽一個有代表性的樣本
→
點估計用 $\bar{x}$ 猜 $\mu$
→
抽樣分配$\bar{x}$ 每次都不一樣
中央極限定理$\bar{x}$ 近似常態
→
標準誤差$\dfrac{\sigma}{\sqrt{n}}$，$n$ 越大越準
→
信賴區間$\bar{x} \pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$
只抽一次樣本，我們說不出 $\mu$ 的確切值，但可以說出「有 95% 的信心，$\mu$ 落在這個範圍」

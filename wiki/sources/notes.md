## 重點

### ch3（p.5、p.6）

- 中位數較不受極端值影響，計算前資料要從小排到大（p.5）
- 樣本變異數 $s^2 = \sum(x_i - \bar{x})^2/(n-1) = (\sum x_i^2 - n\bar{x}^2)/(n-1)$，分母的 $n-1$ 用紅字標出；母體變異數的分母是 $N$（p.5）
- 標準差和資料同單位，比較好解釋（p.5）
- 偏態的三種情況，並畫出右偏、對稱、左偏時眾數、中位數、平均數的位置（p.5、p.6）
- z-score 兩種寫法：$z_i = (x_i - \bar{x})/s$、$z_i = (x_i - \mu)/\sigma$（p.6）
- 柴比雪夫定理適用於不知道分配的時候，$k > 1$，k 不用是整數；經驗法則適用於鐘型分布，0.6826、0.9545、0.9973（p.6）
- 離群值：$|z| > 3$，可能是紀錄錯或不是同一組資料（p.6）

### ch6（p.13、p.14）

- 連續隨機變數不能算特定值的機率；$f(x)$ 是機率密度函數，是曲線高度的數學式（p.13）
- $X \sim N(\mu, \sigma^2)$ 是一般常態分配，不能查表；對稱、偏態為 0；由 μ 和 σ 決定；曲線下的面積是機率，總和是 1；平均數 = 中位數 = 眾數（p.13）
- 畫出「變異數一樣、μ 不一樣」和「變異數不一樣、μ 一樣」兩組曲線（p.13）
- $Z = (X - \mu)/\sigma \sim N(0, 1)$，可以查 z 值表，注意 $N(0, 1)$ 的第二個參數是變異數（p.14）
- 有沒有等號都不會影響機率，因為一個值沒有機率，要一段才有；連續時才是如此，離散時等號會影響（p.14）
- 練習：$P(X > \mu + 3\sigma) = P(Z > 3) = (1 - 0.9973)/2 \approx 0.0013$（p.14）
- 練習：$P(\mu + \sigma < X < \mu + 2\sigma) = P(1 < Z < 2) = (0.9545 - 0.6826)/2 = 0.1360$（p.14）
- z 值表給的是 $P(Z < z) = P(-\infty < Z < z)$；要會給機率反推 z 值、用 z 值反推 x 值（p.14）

### ch7（p.18 到 22）

- 找有母體代表性的樣本誤差比較小，樣本不夠多誤差較大，抽樣一定存在誤差，適當的抽樣方法有好的母體估計（p.18）
- 估計分成點估計和區間估計（p.19）
- 估計量是數學式，是隨機變數：$\bar{X}$、$s^2$（筆記寫成 $s$，見疑點）、$\hat{p}$；代數字進去算出來的是點估計值，例如 $\bar{x} = (6904 + \dots + 7125)/30 = 7018$（p.19）
- 簡單隨機抽樣（iid）：每個樣本被選到的機率一樣，來自同一個母體、同一個分配，每個被選的都獨立；例如量全校同學身高之前，每個 $X_i$ 都跟母體同分配（p.19）
- 抽樣分配：$\bar{x}$ 的抽樣分配，因為抽的人會不一樣（p.19）
- 標準化的時候 $\sigma^2$ 要記得開根號（p.19）
- 抽 500 次、每次 n = 30，做 500 個 $\bar{x}$ 的直方圖，看對稱、$E(\bar{X})$、$V(\bar{X})$；隨著 n 增加，標準誤差會變小（p.20）
- 如果母體是常態分配，無論 n 是多少，$\bar{x}$ 都是常態；條件 n ≥ 30（CLT）（p.20）
- CLT：X 不知道分配時 $\bar{X}$ 也不知道分配，無法推論；n → ∞ 時 $\bar{X} \sim N(\mu, \sigma^2/n)$，n ≥ 30（p.21）
- $\sigma_{\bar{x}} < \sigma$，n 越大越陡，曲線下面積是 1（p.21）
- EAI 例子：$\bar{X} \sim N(51800, 4000^2/30)$，標準化得 $P(-0.68 < Z < 0.68)$（p.21）
- 點估計量的性質：不偏是期望值等於母體參數，$E(\bar{X}) = \mu$；有效是兩個不偏估計量中變異數較小者；一致是 $\lim_{n \to \infty} V(\hat{\theta}) = 0$，例如 $\lim \sigma^2/n = 0$（p.22）

### ch8（p.24 到 27）

- 區間估計是看點估計跟母體參數有多近（p.24）
- 信賴區間（σ 已知）的條件：$\bar{X}$ 近似常態分配，也就是 $X \sim N(\mu, \sigma^2)$ 或 n ≥ 30 by CLT（p.24）
- $\bar{x} \pm E$，上下界不要寫反；信賴係數（信心度）是發生的機率 $1 - \alpha$；區間寬度 = 上界 − 下界 = 2E（p.24）
- 由 $P(|\bar{X} - \mu| < E) = 1 - \alpha$ 推出 $z_{0.05} = 1.645$、$z_{0.025} = 1.96$、$z_{0.005} = 2.575$；$E = z_{\alpha/2}\sigma/\sqrt{n}$（p.24）
- 推導 $(1-\alpha)$ 信賴區間 $\bar{x} \pm z_{\alpha/2}\sigma/\sqrt{n}$（p.25）
- 信賴係數越大，E 越大，信賴區間越寬；n 越大，E 越小（信賴係數和 σ 不變）；$n = (z_{\alpha/2}\sigma/E)^2$，n 有小數要無條件進位取整數（p.25）
- 信賴區間（σ 未知）的條件：母體是常態分配或不嚴重偏離常態；$t = (\bar{X} - \mu)/(s/\sqrt{n}) \sim t(n-1)$；t 分配比標準常態分配矮胖，隨自由度增加越來越陡；n → ∞ 時 $t(n-1) \sim Z$（p.26）
- 自由度 $v = n - 1$（p.26）
- n ≥ 30 時 $\mu = \bar{x} \pm z_{\alpha/2}\,s/\sqrt{n}$，n 很大時 t 統計量近似標準常態；t 分配通常用在 n < 30、σ 未知、母體常態或不嚴重偏離常態時（p.26）
- 推導 σ 未知時的信賴區間 $\bar{x} \pm t_{\alpha/2}(n-1)\,s/\sqrt{n}$（p.27）

## 疑點

以下都已看圖片確認，使用者同意 Wiki 寫正確的版本，原文記在這裡（2026-11-23）

- **p.20 標準誤差**：把 $\sigma^2/n$ 圈起來標成「標準誤差」，但 $\sigma^2/n$ 是 $\bar{X}$ 的變異數，標準誤差是 $\sigma/\sqrt{n}$（[ch7](ch7.md) p.47）；使用者在講義 ch7 p.63 的手寫是正確的；p.22 也把 $p(1-p)/n$ 標成標準誤差，是同一類筆誤
- **p.19 少了平方**：寫成 $s = \sum(X_i - \bar{X})^2/(n-1)$，這個式子是 $s^2$（[ch3a](ch3a.md) p.45）
- **p.5 母體平均數的符號**：寫成 $\bar{x} = \sum x_i/N$，母體平均數應為 $\mu$（[ch3a](ch3a.md) p.8）
- **p.6 右偏的條件**：寫「skewness 是正的且大於 1.0」，講義是「右偏時偏態為正，高度右偏時常大於 1.0」（[ch3b](ch3b.md) p.4），租金資料偏態 0.92 也是右偏
- **p.13 機率是高度**：寫「連續隨機變數不能算特定值機率，而是算高度」，但機率是曲線下的面積（[ch6](ch6.md) p.5），$f(x)$ 才是高度；同一頁下方也寫了「曲線下的面積是機率」；講義 ch6 p.2 的手寫是同一句話
- **p.6 離群值**：只寫「可能是紀錄錯或不是同一組資料」，講義另外提到也可能是正確且屬於這組資料的值（[ch3b](ch3b.md) p.21），不算錯誤，但不完整
- **p.26 σ 未知且 n ≥ 30 時用 z**：講義的做法是 σ 未知一律用 t（[ch8](ch8.md) p.74），並說自由度超過 100 時 z 才是 t 的好近似（[ch8](ch8.md) p.60）；使用者決定採用筆記的做法，理由是 n ≥ 30 的意思大約是 n 趨近無限大，此時 t 接近 z（2026-11-23）
- **p.24 $z_{0.005} = 2.575$**：與講義 ch8 p.5 手寫相同，已依使用者之前的決定採用 2.576
- **p.19 例子 7018**：$\bar{x} = (6904 + \dots + 7125)/30 = 7018$ 在講義中找不到對應的資料，無法驗算，只作為「估計值」的示意

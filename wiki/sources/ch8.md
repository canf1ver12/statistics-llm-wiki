# ch8：區間估計

## 一句話摘要

點估計值不可能剛好等於母體參數，所以改用「點估計值 ± 邊際誤差」建立信賴區間；σ 已知時母體平均數的區間為 $\bar{x} \pm z_{\alpha/2}\,\sigma/\sqrt{n}$

## 重點

### 為什麼需要區間估計

- 點估計量不可能提供母體參數的精確值；區間估計是在點估計值加減一個邊際誤差，目的是提供「點估計值離母體參數有多近」的資訊（p.8、p.10）
- Food Lion 超市用 95% 信賴水準算出 LIFO 指數的邊際誤差為 0.006，區間 1.009 到 1.021 是 95% 信賴區間（p.2）

### σ 已知時的區間估計

- 計算邊際誤差需要母體標準差 σ，σ 很少能精確知道，但常可以從歷史資料得到好的估計值，這種情況稱為 σ 已知（p.13）
- 有 $1 - \alpha$ 的機率，樣本平均數的邊際誤差會小於等於 $z_{\alpha/2}\,\sigma_{\bar{x}}$（p.14）
- 用不同樣本建立的區間，有的包含 μ、有的不包含（p.15）
- 母體平均數的區間估計為 $\bar{x} \pm z_{\alpha/2}\,\sigma/\sqrt{n}$，其中 $1 - \alpha$ 是信賴係數，$z_{\alpha/2}$ 是標準常態分配右尾面積為 $\alpha/2$ 的 z 值（p.39）
- 常用信賴水準的 z 值：90% 為 1.645、95% 為 1.960、99% 為 2.576（p.40）
- 90% 的區間 $\bar{x} \pm 1.645\,\sigma_{\bar{x}}$ 會包含母體平均數，所以說「有 90% 的信心這個區間包含母體平均數」，0.90 稱為信賴係數（p.19、p.35）
- 範例：$\bar{x} = 50$、$n = 36$、$\sigma = 5$ 的 95% 信賴區間為 $50 \pm 1.96 \times 5/\sqrt{36}$，區間寬度為 $2 \times 1.96 \times 5/\sqrt{36}$（p.26）

### Lloyd's 百貨

- 每週抽 100 位顧客，了解每次購物的花費，根據歷史資料假設 σ = 20（p.9）
- 標準誤差 $\sigma_{\bar{x}} = 2$，$1.96 \times 2 = 3.92$，所以 n = 100 時 95% 的 $\bar{x}$ 會落在 μ ± 3.92 之內（p.31）
- 因為 95% 的 $\bar{x}$ 落在深色區域，用 $\bar{x} \pm 3.92$ 建立的區間有 95% 會包含 μ（p.36）
- 最近一週 $\bar{x} = 82$，區間為 82 − 3.92 = 78.08 到 82 + 3.92 = 85.92（p.37）
- 因為用 $\bar{x} \pm 3.92$ 建立的區間有 95% 會包含 μ，所以說有 95% 的信心 78.08 到 85.92 包含 μ，0.95 是信賴係數，這個區間叫做 95% 信賴區間（p.38）
- 信賴水準 90%、95%、99% 的邊際誤差分別為 3.29、3.92、5.15，區間分別為 78.71 到 85.29、78.08 到 85.92、76.85 到 87.15；信賴水準越高，邊際誤差和區間寬度越大（p.44，講義標題筆誤已更正，見疑點）

### Discount Sounds

- 新分店商圈的家戶年所得：n = 36、$\bar{x}$ = 41,100、母體不太偏斜、σ 估計為 4,500、信賴係數 0.95（p.41）
- 邊際誤差 $1.96 \times 4{,}500/\sqrt{36} = 1{,}470$（p.42）
- 95% 信賴區間為 41,100 ± 1,470，也就是 39,630 到 42,570（p.43）

### 樣本數

- 多數應用 n = 30 就足夠；母體高度偏斜或有離群值時建議 n ≥ 50（p.45）
- 母體至少近似常態時 n 小於 15 也可以；不是常態但大致對稱時 n = 15 就夠（p.46）
- 由 $E = z_{\alpha/2}\,\sigma/\sqrt{n}$ 可得 $n = (z_{\alpha/2}\,\sigma/E)^2$（p.28 到 30）
- 例：95% 信賴、σ = 9.65、希望邊際誤差為 2，$n = (1.96 \times 9.65/2)^2 = 89.43$，取 n = 90（p.29）
- 例：n = 100、95% 信賴、σ = 9.65，邊際誤差 $E = 1.96 \times 9.65/\sqrt{100} = 1.89$（p.30，講義筆誤已更正，見疑點）

### σ 未知時

- 抽樣前無法估計 σ 時，用樣本標準差 s 估計 σ，稱為 σ 未知，區間估計改用 t 分配（p.53）
- t 分配是一族分配，由自由度決定；自由度是計算 s 時用到的獨立資訊個數（p.55）
- 自由度越大，t 分配越集中，和標準常態分配的差異越小（p.56、p.57）
- σ 可假設已知時用 $\bar{x} \pm z_{\alpha/2}\,\sigma/\sqrt{n}$，否則用 $\bar{x} \pm t_{\alpha/2}\,s/\sqrt{n}$（p.74）

## 手寫註記

- p.3：信賴區間（C.I.，Confidence Interval）
- p.4：$\bar{x}$ 是 μ 的點估計值；「$\bar{x}$ 要近似常態分配（by CLT，一定要寫）」；95% 信賴區間為 $\bar{x} \pm E$，也就是 $(\bar{x} - E, \bar{x} + E)$；$P(|\bar{X} - \mu| \le E) = 1 - \alpha$ 是發生的機率；信賴係數（confidence coefficient）又稱信心度；並畫出兩個區間，一個包含 μ、一個沒包含
- p.5：由 $P(|Z| < E/(\sigma/\sqrt{n})) = 1 - \alpha$ 推出 $z_{0.05} = 1.645$、$z_{0.025} = 1.96$、$z_{0.005} = 2.575$，並畫出兩尾各 $\alpha/2$ 的圖
- p.6：$E = z_{\alpha/2}\,\sigma/\sqrt{n}$（σ 已知）
- p.8：區間估計是看點估計跟母體參數有多近
- p.22：推導 $P(\bar{X} - z_{\alpha/2}\sigma/\sqrt{n} < \mu < \bar{X} + z_{\alpha/2}\sigma/\sqrt{n}) = 1 - \alpha$；「上界跟下界不要寫反」
- p.23：範例 n = 36、σ = 5、$\bar{x}$ = 50 的 95% 信賴區間 $50 \pm 1.96 \times 5/6$；區間寬度 = 上界 − 下界 = $2E$
- p.24：n 增加時 E 變小（$1 - \alpha$、σ 不變）；信賴係數一樣時，n 大區間窄比較好，n 小區間寬；$n = (z_{\alpha/2}\sigma/E)^2$
- p.29：n 有小數時要無條件進位取整數
- p.44：信賴係數越大，E 越大，信賴區間越寬
- p.55：自由度 n−1
- p.57：t 隨著 n 增加會變陡

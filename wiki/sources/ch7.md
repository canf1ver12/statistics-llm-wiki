# ch7：抽樣與抽樣分配

## 一句話摘要

樣本平均數 $\bar{x}$ 會隨抽到的樣本而改變，它的機率分配叫做抽樣分配，期望值為 $\mu$、標準誤差為 $\sigma/\sqrt{n}$，而且根據中央極限定理，樣本夠大時近似常態分配

## 重點

### 母體、樣本與抽樣

- 母體是所有感興趣元素的集合，樣本是母體的子集合，抽樣框是抽樣時使用的元素清單（p.6）
- 樣本結果只能提供母體特性的估計值，因為樣本只包含母體的一部分；用適當的抽樣方法，樣本結果可以是「好的」估計（p.7）
- EAI 公司要了解 2,500 位經理的資料，但沒有全部資料，改抽 30 位經理當樣本（p.8）
- 從有限母體抽出的簡單隨機樣本：每一個大小為 n 的可能樣本被抽中的機率都相同（p.10）
- 抽後不放回是最常用的方式（p.11）
- 無限母體的隨機樣本要滿足：每個元素都來自感興趣的母體、每個元素獨立選取，以避免選擇偏誤（p.18）
- 目標母體和實際抽樣的母體要盡量一致（p.32）
- 建議使用機率抽樣方法，因為只有機率抽樣能評估樣本結果有多接近母體參數，便利抽樣和判斷抽樣無法評估（p.135）

### 點估計

- 點估計是用樣本資料算出樣本統計量，當作母體參數的估計值，是統計推論的一種形式；$\bar{x}$、$s$、$\bar{p}$ 分別是 $\mu$、$\sigma$、$p$ 的點估計量（p.24）
- St. Andrew's College 900 位申請者中抽 30 位：樣本 $\bar{x} = 1684$、$s = 85.2$、$\bar{p} = 0.67$（p.29）；母體 $\mu = 1697$、$\sigma = 87.4$、$p = 0.72$（p.30、p.31）
- 換一組亂數會抽到不同樣本，得到不同的點估計值（p.29）

### 抽樣分配

- EAI 例子：從 2,500 位經理中抽 30 人算 $\bar{x}$，重複 500 次，$\bar{x}$ 的相對次數直方圖呈鐘形（p.35 到 37、p.42）
- 實務上只會抽一個簡單隨機樣本，重複 500 次只是為了說明不同樣本會產生不同的統計量（p.42）
- $\bar{x}$ 的抽樣分配是 $\bar{x}$ 所有可能值的機率分配（p.45）
- $E(\bar{x}) = \mu$；點估計量的期望值等於母體參數時，稱為不偏（p.45）
- $\sigma_{\bar{x}}$ 是 $\bar{x}$ 的標準差，$\sigma$ 是母體標準差（p.46）
- 無限母體時 $\sigma_{\bar{x}} = \sigma/\sqrt{n}$，有限母體要乘上校正因子 $\sqrt{(N-n)/(N-1)}$；$n/N \le 0.05$ 時可視為無限母體；$\sigma_{\bar{x}}$ 稱為平均數的標準誤差（p.47、p.49）
- EAI：$\sigma = 4{,}000$、$N = 2{,}500$、$n = 30$，$n/N = 0.012 \le 5\%$，$\sigma_{\bar{x}} = 4{,}000/\sqrt{30} = 730.3$（p.50，講義筆誤已更正，見疑點）
- 母體為常態時，任何樣本數下 $\bar{x}$ 的抽樣分配都是常態；母體高度偏斜或有離群值時可能需要 n = 50；多數應用中 n ≥ 30 就可以用常態近似（p.51）
- $\bar{x}$ 的抽樣分配可以提供「$\bar{x}$ 離 $\mu$ 有多近」的機率資訊（p.52）
- 中央極限定理：從母體抽出大小為 n 的隨機樣本，當 n 變大時，$\bar{x}$ 的抽樣分配可以用常態分配近似（p.53）
- 中央極限定理示意圖：均勻、V 字形、右偏三種母體，在 n = 2、5、30 時 $\bar{x}$ 的抽樣分配（p.55、p.56）
- EAI：$E(\bar{x}) = 51{,}800$、$\sigma_{\bar{x}} = 730.3$（p.57）

### 抽樣分配的用途與樣本數

- EAI n = 30：$\bar{x}$ 落在 51,300 到 52,300（μ ± 500）的機率，$z = \pm 0.68$，$P = 0.7517 - 0.2483 = 0.5034$（p.58 到 62）
- EAI n = 100：$E(\bar{x})$ 不受樣本數影響，標準誤差降為 $4{,}000/\sqrt{100} = 400$，同一區間的機率提高為 0.7888（p.66 到 68）
- SAT n = 30：$\sigma_{\bar{x}} = 87.4/\sqrt{30} = 15.96$（p.69）；$\bar{x}$ 落在 1687 到 1707 的機率，$z = (1707 - 1697)/15.96 = 0.63$（p.72），$P(-0.63 \le z \le 0.63) = 0.7357 - 0.2643 = 0.4714$（p.75，講義筆誤已更正，見疑點）
- SAT n = 100：使用有限母體校正，標準誤差降為 8.2，同一區間的機率提高為 0.7776（p.77 到 79）

### 點估計量的性質

- 用 $\theta$ 表示母體參數，$\hat{\theta}$ 表示它的點估計量（p.109）
- 好的點估計量要有三個性質：不偏、有效、一致（p.110）
- 不偏：$E(\hat{\theta}) = \theta$（p.111）；p.112 的圖對照不偏和有偏誤的估計量
- 有效：兩個不偏估計量中，標準差較小的比較好，稱為相對有效性較高（p.113）
- 一致：樣本數越大，點估計值越接近母體參數（p.115）

### 抽樣誤差

- 抽樣誤差是隨機抽樣造成的樣本與母體的差異，樣本不可能完全代表母體，n 越大抽樣誤差越小（p.138）
- 非抽樣誤差不是隨機抽樣造成的，例如涵蓋誤差、無反應誤差、測量誤差（p.139）
- s = 20 時，n = 10、10,000、1,000,000、100,000,000、1,000,000,000 的標準誤差分別為 6.32456、0.2、0.02、0.002、0.00063（p.140）

## 手寫註記

- p.7：找有母體代表性的樣本誤差比較小，樣本不夠多誤差較大，抽樣一定存在誤差
- p.19：$\bar{X} = (X_1 + X_2 + \dots + X_n)/n$，圈出 $X_1, \dots, X_n$ 標「隨機變數」；$\bar{X}$ 是估計量（estimator，隨機變數），代入資料算出的 $\bar{x} = 166$ 是點估計值；「$\bar{x}$ 的抽樣分配（有不一樣的 $\bar{x}$），因為抽的人會不一樣」
- p.20：$s^2 = \sum(X_i - \bar{X})^2/(n-1)$ 是估計量（UMVUE），$s^2 = 49$ 是點估計值；$\hat{p} = X/n$ 樣本比例
- p.34：抽 500 次、每次 n = 30，得到 500 個 $\bar{x}$，做直方圖看三件事：對稱、500 個 $\bar{x}$ 的平均值 $E(\bar{X})$、變異數 $V(\bar{X})$；$\bar{X}$ 是隨機變數，平均值就是期望值
- p.38：推導 $E(\bar{X}) = \mu$ 和 $V(\bar{X}) = \sigma^2/n$，並寫「都是 X」表示每個 $X_i$ 都和 X 同分配，但箭頭旁寫成 $X_i \sim N(\mu, \sigma_{\bar{x}}^2)$，見疑點
- p.39：n ≥ 30（or 25）
- p.48、p.64：iid 獨立同分布，樣本互相獨立；量身高之前，每個 $X_i$ 都跟母體同分配
- p.54：$X \sim ?(\mu, \sigma^2)$ 時 $\bar{X} \sim ?(\mu, \sigma^2/n)$，不知道什麼分配就不能推論；n → ∞ 時 $\bar{X} \sim N(\mu, \sigma^2/n)$，n ≥ 30（CLT），打了星號
- p.55：在第一個母體上標「uniform」
- p.59：把 $P(|\bar{x} - \mu| < 500)$ 標準化成 $P(-0.68 < Z < 0.68)$；抽樣誤差是因為抽到的人不一樣，造成 $\bar{x}$ 不一樣
- p.63：畫出 $x$ 和 $\bar{x}$ 兩條曲線，圈出 $\sigma/\sqrt{n}$ 標「標準誤差」，寫「n 越大越陡」、「曲線下面積是 1」

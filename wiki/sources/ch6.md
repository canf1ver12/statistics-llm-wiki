# ch6：連續機率分配

## 一句話摘要

連續型隨機變數的機率是曲線下的面積，其中最重要的是常態分配，任何常態分配都可以標準化成標準常態分配後查 z 表

## 重點

- 連續型隨機變數不能談某個特定值的機率，單一點是寬度為 0 的區間，所以剛好等於某個值的機率為 0（p.4）
- 隨機變數落在 $x_1$ 到 $x_2$ 之間的機率，是機率密度函數圖形在 $x_1$ 到 $x_2$ 之間的面積（p.5）
- 常態分配是描述連續型隨機變數最重要的分配，廣泛用在統計推論，例如身高、考試成績、雨量、科學測量（p.14）
- 常態分配對稱，偏態為 0（p.18）
- 整個常態分配家族由平均數 $\mu$ 和標準差 $\sigma$ 決定（p.19）
- 常態曲線的最高點在平均數，平均數也是中位數和眾數（p.20）
- 平均數可以是任何數值（p.21）
- 標準差決定曲線的寬度，標準差越大，曲線越寬越扁（p.22）
- 機率是曲線下的面積，總面積為 1，平均數左右各 0.5（p.23）
- 常態分配是經驗法則的基礎：68.26%、95.45%、99.73% 的值分別落在平均數 ±1、2、3 個標準差內（p.27）
- $z = (x - \mu)/\sigma$ 可以想成 $x$ 離 $\mu$ 幾個標準差（p.29、p.45）
- 平均數為 0、標準差為 1 的常態分配叫做標準常態分配，用字母 $z$ 表示（p.30、p.31）
- z 表的數值是 z 左邊的曲線下面積，也就是累積機率，例如 $P(z \le 1.00) = 0.8413$、z = −0.85 時為 0.1977、z = 1.25 時為 0.8944（p.33、p.35、p.37）
- 常見的三種機率：$P(z \le a)$、$P(a \le z \le b)$、$P(z \ge a)$（p.39）
- $P(-0.50 \le z \le 1.25) = 0.8944 - 0.3085 = 0.5859$（p.40）
- $P(-1.00 \le z \le 1.00) = 0.8413 - 0.1587 = 0.6826$（p.41）
- $P(z \ge 1.58) = 1 - 0.9429 = 0.0571$（p.42）
- 反過來給機率求 z：$P(Z > z) = 0.10$ 時 z = 1.28（p.43）
- Grear 輪胎：里程 $\mu = 36{,}500$、$\sigma = 5{,}000$ 的常態分配（p.47）；超過 40,000 英里時 z = 0.70，$P(z \ge 0.70) = 0.2420$，約 24.2%（p.50）；希望最多 10% 的輪胎適用保證時，z = −1.28（p.51），保證里程為 $36{,}500 - 1.28 \times 5{,}000 = 30{,}100$ 英里（p.53）
- Pep Zone 機油：補貨期間的需求為 $\mu = 15$、$\sigma = 6$ 加侖的常態分配（p.55）；需求超過 20 加侖時 $z = (20 - 15)/6 = 0.83$（p.56），缺貨機率 $P(z > 0.83) = 1 - 0.7967 = 0.2033$（p.58）；要讓缺貨機率不超過 0.05，z = 1.645，再訂購點為 24.87 加侖（p.60）

## 手寫註記

- p.2：連續隨機變數不能算特定值機率，而是算高度（見疑點）；probability density function（pdf）是機率密度函數，是高度的數學式；$P(1 < X < 2)$ = area；$X \sim U(1, 3)$，$f(x) = 1/3$（見疑點）
- p.13：標準化之後才能查表
- p.15：$X \sim N(\mu, \sigma^2)$，$E(X) = \mu$、$V(X) = \sigma^2$，並寫「一般常態分配（不能查表）」；圖上標出 $\sigma$ 是 $\mu$ 到反曲點的水平距離
- p.24：$Z = (X - \mu)/\sigma \sim N(0, 1)$，稱為標準常態分配，z 值表給的是機率值；寫了「離散時等號會影響，連續時一個值沒有機率，有沒有等號機率不變」；把 $P(\mu - \sigma < X < \mu + \sigma)$ 標準化成 $P(-1 < Z < 1) = 0.6826$，±2σ 為 0.9545
- p.43：$P(Z < z_0) = 0.9$，$z_0 = 1.28$（or 1.285）
- p.51：計算時寫成 $-z_0 = 1.285$

# ch3a：描述統計：數值方法（上）

## 一句話摘要

用數字描述一組資料的位置（平均數、中位數等）和變異程度（變異數、標準差等），並區分母體參數和樣本統計量

## 重點

- 用樣本資料算出來的量數叫樣本統計量，用母體資料算出來的量數叫母體參數（p.4）
- 樣本統計量是對應母體參數的點估計量，例如樣本平均數 $\bar{x}$ 是母體平均數 $\mu$ 的點估計量（p.4、p.5）
- 樣本平均數 $\bar{x} = \sum x_i / n$，母體平均數 $\mu = \sum x_i / N$（p.7、p.8）
- 例子：12 位商學院畢業生的起薪總和為 47,280，$\bar{x} = 47{,}280 / 12 = 3{,}940$（p.12）
- 少數極端大的數值會把平均數拉高，有極端值時中位數比較適合描述中心位置（p.18）
- 除了位置，也要看變異程度：選供應商時，除了平均交貨天數，交貨天數穩不穩定也很重要（p.38）
- 變異數是每筆資料與平均數之差（離均差）平方後的平均（p.44、p.45）
- 樣本變異數 $s^2 = \sum (x_i - \bar{x})^2 / (n-1)$，母體變異數 $\sigma^2 = \sum (x_i - \mu)^2 / N$（p.45）
- 例子：班級人數 46、54、42、46、32，$\bar{x} = 44$，離均差總和為 0，離均差平方和為 256，$s^2 = 256/4 = 64$（p.46）
- 標準差是變異數的正平方根，單位和原始資料相同，比變異數好解釋（p.48、p.49）
- 標準差常用來衡量股票投資的風險（p.50）

## 手寫註記

- p.4：數學式寫成大寫 $\bar{X}$，是隨機變數；小寫 $\bar{x}$ 是把資料代入數學式後的統計量的值，例如 $s^2 = 49\ \text{cm}^2$
- p.4：母體參數要有所有母體資料才算得出來，是固定的，例如 $\mu$、$\sigma^2$；並標出點估計的對應 $\mu \leftarrow \bar{x}$、$\sigma^2 \leftarrow s^2$
- p.45：樣本變異數分母的 $n-1$ 用紅筆圈起來特別強調
- p.51：黃筆圈起「In normal, s and $\bar{x}$ are indep. Not for nonnormal」並畫了問號，見下方疑點
